# 💡Interactive Lamp Switch
Интерактивная лампочка с физикой верёвки-выключателя. Потяните за шнур, чтобы включить/выключить свет.
    
## ✨ Особенности

🎨 Плавная анимация SVG верёвки с физикой
💡 Динамическое свечение лампы
🖱️ Интуитивный drag & drop интерфейс
⚡ Построено на GSAP для производительных анимаций
🎭 Анимированный текст с эффектом появления   

## 🛠️ Технологии

React + TypeScript
GSAP (GreenSock Animation Platform)
Vite для быстрой разработки
Tailwind CSS для стилизации

## 📦 Установка
```typescript
# Клонировать репозиторий
git clone https://github.com/yourusername/interactive-lamp.git

# Перейти в директорию
cd interactive-lamp

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev
```

## 🎮 Использование

1. Наведите курсор на круглую ручку внизу лампы
2. Зажмите и потяните вниз
3. Отпустите — лампа переключится!
